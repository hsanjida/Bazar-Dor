# 🛒 বাজার দর (BazarDor) — নিত্যপ্রয়োজনীয় পণ্যের বাজার মনিটরিং প্ল্যাটফর্ম

[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4-38B2AC?style=for-the-badge&logo=tailwind-css)](https://tailwindcss.com/)

**বাজার দর (BazarDor)** একটি আধুনিক, রেসপন্সিভ এবং রিয়েল-টাইম মার্কেট প্রাইস মনিটরিং ওয়েব অ্যাপ্লিকেশন। প্রতিদিনের চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম ও মসলার পাইকারি ও খুচরা বাজারদর, সর্বোচ্চ ও সর্বনিম্ন দামের তারতম্য, বাজারভিত্তিক তুলনামূলক বিশ্লেষণ এবং মূল্য পরিবর্তনের হালনাগাদ তথ্য এক নজরে সাধারণ ক্রেতাদের কাছে পৌঁছে দিতে এটি তৈরি করা হয়েছে।

## 🌟 প্রধান ৫টি বৈশিষ্ট্য (5 Key Features)

1. **রিয়েল-টাইম প্রাইস টিকার ও মূল্য ওঠানামা ট্র্যাকিং (Real-time Price Ticker & Price Movers):**
   - ওয়েবসাইটের শীর্ষে অবিরাম স্ক্রলিং প্রাইস টিকার (Marquee Strip), যেখানে প্রতিটি পণ্যের বর্তমান দাম, একক এবং পূর্ববর্তী দিনের তুলনায় শতকরা মূল্যবৃদ্ধির (▲ লাল) বা হ্রাসের (▼ সবুজ) হার তাৎক্ষণিক প্রদর্শিত হয়।
   - হোমপেজে স্বয়ংক্রিয়ভাবে ফিল্টার করা **"আজ দাম বেড়েছে ▲"** (Top 6 Risers) এবং **"আজ দাম কমেছে ▼"** (Top 6 Fallers) সেকশন।

2. **সম্পূর্ণ বাংলা সংখ্যা ও মুদ্রা রূপান্তর (Native Bengali Formatting):**
   - ওয়েবসাইটের সমস্ত দাম, পরিসংখ্যান, শতাংশ এবং তারিখ স্বয়ংক্রিয়ভাবে বাংলা সংখ্যা (যেমন: `১৪৮ টাকা`, `২.১%`, `মঙ্গলবার, ৬ অক্টোবর, ২০২৬`) এবং আন্তর্জাতিক কমা ফরম্যাটে প্রদর্শিত হয়।

3. **ক্যাটাগরিভিত্তিক ফিল্টারিং ও সঠিক সাংখ্যিক বাছাই (Category Filter & Numeric Sorting — C1):**
   - চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ এবং মসলা ক্যাটাগরির জন্য পৃথক ভিউ।
   - **চ্যালেঞ্জ C1 সম্পন্ন:** দামের ঊর্ধ্বমুখী ও নিম্নমুখী ক্রমানুসারে বাছাই (`ডিফল্ট`, `দাম: কম থেকে বেশি`, `দাম: বেশি থেকে কম`), যা বাংলা সংখ্যার পরিবর্তে অন্তর্নিহিত গাণিতিক মানের ওপর ভিত্তি করে নিখুঁতভাবে সর্ট করে।

4. **সুরক্ষিত প্রোডাক্ট বিস্তারিত ও বাজারভিত্তিক তুলনা (Protected Product Details & Market Breakdown):**
   - অথেনটিকেশন দ্বারা সুরক্ষিত রুট (`/product/[slug]`); অননুমোদিত ব্যবহারকারীদের স্বয়ংক্রিয়ভাবে নোটিফিকেশনসহ সাইন-ইন পেজে রিডাইরেক্ট করা হয়।
   - পণ্যের বিস্তারিত পেজে কারওয়ান বাজার, মিরপুর গ্রিন মার্কেট, সদর বাজার, চৌদগ্রাম বাজারসহ বিভিন্ন বিভাগের সর্বনিম্ন, সর্বাধিক ও গড় দামের তুলনামূলক টেবিল এবং পরিসংখ্যান কার্ড।

5. **বেটার-অথ ইন্টিগ্রেশন ও প্রোফাইল তথ্য আপডেট (BetterAuth & Profile Update — C3):**
   - ইমেইল/পাসওয়ার্ড ও সোশ্যাল লগইন (Google ও GitHub) সুবিধা।
   - সেশন পারসিস্টেন্স এবং তাৎক্ষণিক প্রতিক্রিয়াশীল Toast নোটিফিকেশন (`react-hot-toast`)।
   - **চ্যালেঞ্জ C3 সম্পন্ন:** প্রোফাইল পেজে (`/profile`) ব্যবহারকারীর নাম পরিবর্তনের ডাইনামিক আপডেট ফর্ম এবং তাৎক্ষণিক স্টেট সিঙ্ক্রোনাইজেশন।

## 📡 এপিআই তথ্য (API Endpoints Used)

অ্যাপ্লিকেশনটিতে ৩ স্তরের ফলব্যাকসহ নিচের নির্ভরযোগ্য এন্ডপয়েন্টগুলো ব্যবহৃত হয়েছে:
- **Base URL 1:** `https://openapi.programming-hero.com/api/bazardor`
- **Base URL 2:** `https://api.api-store.workers.dev/api/bazardor`
- **Base URL 3:** `https://api.abcz.workers.dev/api/bazardor`

### প্রধান রুটসমূহ:
- সমস্ত পণ্য: `/products`
- ক্যাটাগরি ফিল্টার: `/products?category={categorySlug}`
- নির্দিষ্ট পণ্য: `/products/{id}`
- সমস্ত ক্যাটাগরি: `/categories`

## 💻 স্থানীয়ভাবে চালনা নির্দেশিকা (How to Run Locally)

### ১. রিপোজিটরি ক্লোন বা ডিরেক্টরিতে প্রবেশ করুন:
```bash
cd B14-A7-Bazar-Dor
```

### ২. প্রয়োজনীয় ডিপেনডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করে অ্যাপ্লিকেশনটি দেখুন।

### ৪. প্রোডাকশন বিল্ড তৈরি ও পরীক্ষা করুন:
```bash
npm run build
npm start
```

## 🏆 চ্যালেঞ্জ রিকোয়ারমেন্টস বাস্তবায়ন (Challenge Implementation)

- **C1. সর্ট ড্রপডাউন (Sort Dropdown):** বাংলা সংখ্যার সাধারণ স্ট্রিং সর্টিংয়ের ত্রুটি পরিহার করে ব্যাকএন্ড সাংখ্যিক মান (`numeric value`) অনুযায়ী `কম থেকে বেশি` ও `বেশি থেকে কম` নিখুঁতভাবে সর্ট করা হয়েছে।
- **C2. তথ্যবহুল README (GitHub README):** প্রজেক্টের সামগ্রিক পরিচিতি, ফিচার, আর্কিটেকচার ও রান করার নির্দেশনাসহ পূর্ণাঙ্গ ডকুমেন্টেশন।
- **C3. তথ্য আপডেট ফিচার (Update Information Feature):** `/profile` রুটে নাম আপডেটের জন্য ফর্ম যুক্ত করা হয়েছে, যা BetterAuth প্যাটার্ন অনুযায়ী তাৎক্ষণিকভাবে ইউজারের নাম হালনাগাদ করে।
